# 심화 과정 — 모터 하나에서 걸음새까지, 그리고 DYNAMIXEL로 직접 만드는 로봇개

## 1. 목표와 흐름
기본 과정에서는 `dog.forward()`처럼 "무엇을 할지"만 명령했다. 심화 과정에서는 그 명령이 **관절 12개의 어떤 움직임으로 이루어지는지** 직접 만들어 본다. 그다음 그 지식으로 **DYNAMIXEL 8개짜리 작은 로봇개**를 만들어 같은 코드로 움직인다.

```
[Lite3 3D 시뮬: 관절 모드]  ──같은 API──▶  [DIY DYNAMIXEL 로봇개: 실물]
 J1 모터 하나                               D1 모터 ID·영점 설정
 J2 자세                                    D2 조립과 방향 보정
 J3 기구학                                  D3 같은 코드로 자세와 기구학
 J4 무게중심                                D4 걸음새 튜닝
 J5 걸음새                                  D5 팀 프로젝트
```
- 실물 Lite3의 관절 직접 제어는 위험하고 보증에도 영향을 준다. 그래서 학생은 **시뮬에서만** 관절을 직접 다룬다. 실물 관절 제어는 교사 시연으로 한정하고, 반드시 호이스트에 매단 상태에서 한다.
- 실물에서 관절을 직접 다루는 경험은 DIY 로봇개가 담당한다. 작고 가벼워서 안전하고, 고장 나도 부품 교체가 싸다.

## 2. 시뮬 실습 (구현과 검증 완료: `sim/proto/joint_lessons/`)

| 차시 | 예제 | 핵심 개념 | 시뮬에서 측정한 결과 |
|---|---|---|---|
| J1 | `j1_one_motor.py` | 목표 각도와 현재 각도, 가동 범위 | 목표 25° → 실제 23.8° (중력과 강성 때문에 오차) |
| J2 | `j2_poses.py` | 자세 = 각도 12개 묶음(리스트·딕셔너리), 보간 | 강아지 앉기 pitch -35°. 0.1초 만에 자세를 바꾸면 "쾅" |
| J3 | `j3_kinematics.py` | 정기구학(삼각함수), 역기구학(코사인 법칙) | 계산값이 MuJoCo 실제 발 위치와 **0.1 mm 이내**로 일치. 팔굽혀펴기, 인사 |
| J4 | `j4_lift_leg.py` | 무게중심, 지지 다각형, 안정 여유 | 서 있을 때 여유 +15.3 cm → 그냥 들면 **−10 cm, 넘어짐(roll −89°)**. 몸을 뒤로 옮긴 뒤 들면 **+6.1 cm, 버팀**. Studio ④ 탭과 3D 화면에서 무게중심·지지 다각형을 눈으로 확인하고, 짐을 올려 무게중심을 옮겨 보는 실험 |
| J5 | `j5_trot.py` | 걸음새 주기, 딛기와 옮기기, 대각선 위상 | 10주기에 +0.86 m (이론값 0.80 m). **강성 kp를 60으로 낮추면 뒤로 간다** |

연결되는 수학·과학 개념: 삼각함수와 코사인 법칙(수학), 무게중심과 토크·마찰(물리), 주기와 위상(수학·물리)

### 학생 API (`lite3_joint_proto.py`) — 딥 로보틱스 공식 인터페이스 위의 얇은 층
시뮬 안에 공식 `interface::RobotInterface`(Lite3_rl_deploy)와 함수 이름, 단위, 형식이 같은 `Lite3SimInterface`(`sim/proto/lite3_interface.py`)를 두었다. 학생 API는 이 인터페이스만 호출한다.

| 학생 함수 | 의미 | 딥 로보틱스 공식 형식 |
|---|---|---|
| `set_angle(leg, joint, deg)` | 목표 각도를 즉시 지정 | `SetJointCommand(12×5)`의 2번째 열(목표각, rad). 예: `("FL", "knee")` = 관절 2번 `FL_Knee_joint` |
| `get_angle(leg, joint)` | 현재 각도 | `GetJointPosition()[i]` (rad → 도) |
| `move_to(pose, seconds)` | 여러 관절을 부드럽게 이동 | 12 ms마다 보간한 목표각으로 `SetJointCommand` |
| `set_stiffness(kp, kd)` | 관절 강성과 감쇠 | 12×5 명령의 1번째(kp)·3번째(kd) 열. 기본값 kp 120, kd 3 (공식 보행은 30/1, 서기·눕기는 100/2.5) |
| `get_foot` / `set_feet` | 정기구학과 역기구학 | 소프트웨어 계산. 공식 서기·눕기 코드도 높이로 관절각을 계산함(`GetHipYPosByHeight`) |
| `dog.robot` | 공식 인터페이스 직접 사용 | `GetJointPosition/Velocity/Torque`, `GetImuRpy/Acc/Omega`, `GetContactForce`, `SetJointCommand`, `GetJointCommand` |

학생은 쉬운 이름과 도 단위로 시작하고, 화면에는 항상 공식 형식(관절 번호, rad)이 함께 보인다. 조작 패널(`studio.py`의 🎛)에서 슬라이더를 움직이면 같은 내용을 눈으로 확인할 수 있다.

토크 어림 계산: 트롯할 때는 두 다리가 몸무게 전체를 받는다. 1 kg 로봇에 링크 10 cm라면 필요한 토크는 약 0.25–0.5 Nm이고, 여유를 두면 약 1 Nm다. 그래서 XL430(1.4 Nm)은 충분하고, XL330(0.52 Nm)은 아슬아슬하다. 연속 부하는 정지 토크의 1/3–1/2 이하로 유지한다.

- PC(또는 Raspberry Pi) + U2D2 + Python 구성이면 학생 코드가 그대로 동작한다. 저렴한 대안은 OpenRB-150($28.64, Arduino 호환)이다. 다만 OpenRB-150을 거쳐 Python SDK를 쓸 수 있는지는 공식 문서에 없어 확인이 필요하다.
- **8자유도에서 빠지는 것**: hip_x(옆으로 벌리기)가 없어서 J4의 "옆으로 무게 옮기기"를 할 수 없다. 그래서 다리 들기는 앞뒤 이동만으로 하거나 트롯 보행으로 대신한다. 이 차이 자체를 "자유도와 할 수 있는 동작의 관계" 토론 소재로 쓴다. 12자유도로 확장하면 모터 4개(+$110)가 더 들고 무게도 늘어나 토크가 더 빠듯해진다.

## 4. 소프트웨어: 같은 코드를 DIY 로봇에서 돌리기
`JointDog("diy")` 백엔드(구현 예정)가 할 일:
1. **Lite3 학생 API → DYNAMIXEL로 옮기기**: `set_angle`은 Goal Position(116), `get_angle`은 Present Position(132), `move_to`는 Profile Velocity(112)와 Sync Write, `set_stiffness`는 Position P Gain(84)에 대응한다.
2. **각도 ↔ DYNAMIXEL 위치값 변환**: `pos = 2048 + 방향 × (각도 + 영점보정) / 0.088`. 관절마다 방향(+1/-1)과 영점을 보정 파일에 저장한다.
3. **동시 제어**: GroupSyncWrite(Goal Position)로 8개를 한 번에 쓰고, GroupSyncRead(Present Position)로 한 번에 읽는다.
4. **링크 길이만 교체**: `THIGH`, `SHANK`를 DIY 치수(예: 각 0.10 m)로 바꾸면 J3~J5 코드가 그대로 동작한다.
5. **안전**: 관절 가동 범위 제한, 토크 켜고 끄기(Torque Enable 64), 과열 시 정지.

준비물: `pip install dynamixel-sdk`(4.1.0), Dynamixel Wizard 2.0(모터마다 ID 1–8 지정, 통신 속도를 1 Mbps로 변경). 기본 설정은 ID 1, 57600 bps, 위치 제어 모드(3)이다.

# 교육 과정 — 고등학생 대상 Lite3 Pro 로봇 활용

## 1. 설계 전제
| 항목 | 내용 |
|---|---|
| 대상 | 고등학생 |
| 사전 지식 | **아주 기초적인 Python**: 변수, print, 간단한 반복문 정도 |
| 원칙 | **기본 조작을 먼저 익히고 AI는 나중에.** 손으로 조작하기 → 원리 이해 → 코드로 조작 → (다음 단계) AI 순서로 올라간다. |
| 분량 | 기본 과정 16차시(1차시 50분 기준, 블록 수업이면 2차시씩 묶음). 차시 수가 정해지면 조정한다. |
| 로봇 대수 | 1대를 가정한다. 4–5명이 한 팀이고, **PC 실습과 로봇 스테이션을 번갈아** 쓴다. |

### 학생에게 감추는 것과 보여 주는 것
- 감춤: ROS2, SSH, C++, 네트워크 설정. 교사 PC가 모두 처리한다.
- 보여 줌: 학생용 Python 라이브러리 `lite3_edu` 하나. 같은 코드가 **3D 시뮬(mock, 실제 로봇 형상) → 실물**에서 그대로 돌아간다(→ [`edu_python_api.md`](edu_python_api.md)).

### 실물 로봇 사용 규칙
- 실물 실행은 **교사 승인제**로 한다. 학생 코드가 mock에서 통과해야 로봇 스테이션에 올라간다.
- 교사는 E-STOP 리모컨과 앱(Auto/Manual 제어권)을 쥔다.
- 학생 라이브러리에 속도 상한(전진 0.3 m/s, 회전 30°/s)과 실행 시간 상한을 넣어 둔다.

## 2. 단원 구성

### 1단원. 로봇개와 친해지기 — 앱 조작 (1–4차시)
| 차시 | 주제 | 활동 | 핵심 개념 |
|---|---|---|---|
| 1 | 4족 보행 로봇과 안전 | 로봇의 구성(다리 4개 × 관절 3개 = 12자유도, 센서, 배터리) 관찰. 안전 수칙 서약. 교사 시연 | 자유도, 액추에이터, 센서 |
| 2 | 앱 조작 기초 | 서기·앉기, Move 모드 조종. 콘 사이를 지나는 슬라럼 | 제어권, 원격 조종 |
| 3 | 보행과 지형 탐구 | Flat과 RUG(General, Grip, H-Step)로 같은 코스를 통과하며 시간과 성공 여부를 기록하는 비교 실험 | 보행(gait), 지형 적응, 실험 설계 |
| 4 | 자세와 좌표계 + **조종 면허 시험** | Pose 모드로 roll, pitch, yaw 체험 → 지정 코스 통과 실기 시험 | 3축 좌표계, 오일러각 |

> 조종 면허를 딴 학생만 이후 실물 조작과 코드 실행 담당을 맡는다(안전 장치이자 동기 부여).

### 2단원. 센서와 똑똑한 기능 — 원리 이해 (5–7차시)
| 차시 | 주제 | 활동 | 핵심 개념 |
|---|---|---|---|
| 5 | 로봇은 어떻게 세상을 볼까 | Auto Stop(초음파), Obstacle Avoidance(깊이), Tracking(카메라)을 하나씩 켜고 반응 관찰 → 각각 어떤 센서를 쓰는지 추론 | 초음파, 깊이 카메라, 비전 |
| 6 | 말로 하는 프로그래밍 | 음성 명령 15종만으로 미로 코스 통과. 먼저 **명령 순서를 종이에 설계**한 뒤 실행 | 알고리즘, 순차 구조, 디버깅 |
| 7 | 로봇의 데이터 읽기 | 교사 대시보드로 걷는 동안 IMU와 배터리 값이 바뀌는 모습 관찰 → 수집한 CSV를 Python으로 출력하고 간단한 그래프 그리기 | 센서 데이터, 리스트, 그래프 |

### 3단원. 파이썬으로 로봇 조작하기 (8–14차시)
같은 과제를 **3D 시뮬(mock, PC 화면의 실제 Lite3 모델) → 실물** 순서로 실행한다.

| 차시 | 주제 | 예시 과제 | Python 개념 |
|---|---|---|---|
| 8 | 첫 번째 로봇 프로그램 | `stand()` → `forward()` → `sit()` | 함수 호출, 순차 실행 |
| 9 | 정사각형 걷기 | 1 m 정사각형 경로 | **for 반복문**, 변수 |
| 10 | 오차와 보정 | 시간으로 돌기와 yaw 센서로 돌기를 비교 → 실물에서 오차 측정 | 측정, 오차, 피드백 개념 |
| 11 | 나만의 동작 만들기 | 동작을 조합한 "댄스" 함수 만들기, 팀별 발표 | **def 함수 정의**, 매개변수 |
| 12 | 조건에 따라 행동하기 | 기울어지면 멈추기, 장애물 앞에서 멈추기 | **if 조건문**, while |
| 13–14 | 팀 미션 | 장애물 코스 통과 프로그램(설계 → mock 검증 → 실물 시연) | 종합 |

### 4단원. 정리와 다음 단계 (15–16차시)
| 차시 | 주제 | 활동 |
|---|---|---|
| 15 | 미션 발표회 | 팀별 실물 시연과 코드 설명 |
| 16 | AI 로봇 미리보기 | 교사 시연: 앱의 사람 추종(Tracking), 카메라 물체 인식, 강화학습 보행 영상 → "로봇이 스스로 배우면?" 토론. 심화 과정 안내 |

## 3. 심화 과정 (기본 과정 이수 후, 2학기·동아리용)
| 모듈 | 내용 | 비고 |
|---|---|---|
| A. 카메라와 비전 | 카메라 영상 받기 → 색깔·물체 찾기 → 따라가기 | OpenCV, YOLO |
| B. AI 음성·언어 명령 | 자연어 → 허용된 동작 목록 → 로봇 | LLM, 안전 계층 설계 |
| C. 강화학습 맛보기 | 시뮬에서 보상을 바꿔 보행 학습 결과 비교(교사 워크스테이션) | rl_training |
| **D. 모터에서 걸음새까지 + DIY 로봇개** | 관절 하나 → 자세 → 기구학 → 무게중심 → 걸음새를 Lite3 시뮬에서 직접 만들고, DYNAMIXEL 8개 로봇개로 실물에 옮김 | → [`advanced_joint_and_diy.md`](advanced_joint_and_diy.md). Lite3 실물 관절 제어는 교사 시연만 |

## 5. 공식 Training Cases와의 관계
`Robot_Training_Cases`(Case 1–11)는 대학·연구자 수준(ROS, C++, 리눅스)이다. 이 과정에서는 다음 용도로만 쓴다.
- Case 1(기초 조작): 1단원 교사용 참고 자료
- Case 2–4(시뮬, 모션, 인지): **교사가 `lite3_edu` 라이브러리를 만들 때 참고**
- Case 7, 10, 11(RL, 추종, LLM): 심화 과정 C, A, B의 소재

# 04. 공식 앱 · 컨트롤러와 응용 방안

## 1. 구성품
| 장치 | 설명 |
|---|---|
| **Controller (리모컨)** | Retroid 계열 안드로이드 휴대용 게임기 형태. "DEEP Robotics" 앱이 설치되어 있으며 물리 스틱과 버튼을 앱의 가상 버튼에 매핑해 쓴다. |
| **Emergency STOP Controller** | 별도의 물리 비상정지 리모컨. 누르면 로봇이 앉은 뒤 **전원을 차단**한다. 비틀어서 해제한다. |
| **"DEEP Robotics" 앱** | Android 6.0 이상(iOS 미지원). 리모컨이나 일반 안드로이드 폰에 설치한다. 로봇 Wi-Fi에 직접 접속한다. |

## 2. 앱 기능 (매뉴얼 2.3절)
- **홈**: 일반 설정(버전, 언어, 기기 정보, MAC 주소), 앨범(스크린샷), 연결, 제어 화면 진입
- **제어 화면**
  - ⑦ **STOP**(소프트 비상정지)
  - Wi-Fi 신호, 로봇·리모컨 배터리 표시
  - 왼쪽 스틱: Move 모드에서는 평행 이동, Pose 모드에서는 pitch·roll
  - 오른쪽 스틱: Move 모드에서는 회전, Pose 모드에서는 높이·yaw
  - Stand/Sit, Move/Pose, Flat/RUG 전환
  - 음성 명령, 스크린샷, 액션 목록
- **보행 모드**
  - Flat: 높이 NRM 또는 Crawl, 속도 저·중·고
  - RUG: General(계단 ≤12 cm, 경사 ≤30°), Grip(경사 ≤40°, 미끄러운 바닥), H-Step(계단 ≤15 cm)
  - AI Base: 최대 0.8 m/s, 계단 ≤18 cm. MAC 주소를 고객지원에 보내 키를 받아 잠금 해제해야 하며, **잠금 해제하면 관절·다리 보증이 3개월로 줄어든다.**
- **액션**: Hello, Twist, Moonwalk, Long Jump, Twist Jump, Backflip 등. 점프나 백플립 전에는 확인 창이 뜬다.
- **음성 명령** 15종 (영어·중국어)
  - stand up / get down
  - go forward·backward·left·right (각 5초)
  - stop
  - look up·down·left·right
  - turn left·right (90°), turn around (180°)
  - say hello
- **설정 화면**
  - Motion: Keep Stepping, Lab Mode, AI 잠금 해제, Reset to Zero, Save Data(고장 로그)
  - Perception: 영상 스트림, Smart Sensing
    - Tracking: 화면에 표시된 사람을 탭해서 추종 대상으로 지정. **추종 중에는 장애물 감지가 꺼진다.**
    - Auto Stop: 전·후방 장애물 앞에서 감속·정지
    - Obstacle Avoidance: 장애물 우회
    - **Auto Mode**: 2차 개발 프로그램에 제어권을 넘김. 매뉴얼에는 "LiDAR 에디션만 지원"이라고 되어 있으나 Lite3_ROS의 `/cmd_vel` 테스트 절차에도 자동 모드 전환이 나온다 ⚠️ Pro 에디션에서 지원되는지 실물로 확인할 것
  - Other: 스피커, 버튼 이름 표시, 액션 이중 확인

## 3. 열려 있는 확장 지점 (사실 확인된 것)

| # | 확장 지점 | 근거 | 확장 가능성 |
|---|---|---|---|
| A | **리모컨 → 개발 PC로 UDP 버튼 이벤트 전송** | `DeepRoboticsLab/gamepad`. 리모컨에 `controlapp.apk`를 설치하고 PC IP와 포트(기본 12121)를 지정. C++ `RetroidGamepad rc(12121)` | 공식 리모컨을 **학생 프로그램의 입력 장치**로 그대로 쓸 수 있음 |
| B | **rl_deploy / sdk_deploy의 Retroid 입력** | Y/A/X 버튼으로 상태 머신 조작 | 학생이 만든 RL 정책을 공식 리모컨으로 시연 |
| C | **앱 Auto ↔ Manual 전환 = 제어권 중재** | 자동 모드에서만 `/cmd_vel`이 반영됨. 수동 모드나 STOP으로 즉시 회수 | **교사가 앱을 쥐고 학생 코드를 승인하거나 회수하는** 안전 인터록 |
| D | **영상 스트림 (RTSP)** | 인지 개발 매뉴얼 | PC에서 OpenCV, YOLO, VLM으로 처리하는 비전 실습 |
| E | **앱 ↔ 인지 호스트 통신** | Lite3_ROS의 `Jetson2App.cpp`(AppReceiver: 앱 명령 수신, 리모컨 상태 발행) | 앱 버튼과 상태를 ROS 토픽으로 받아 쓰는 확장(소스 분석 필요) |
| F | **`/simple_cmd`, `/complex_cmd`** | transfer_interfaces | 서기·앉기, 보행 전환, 액션 같은 앱 기능을 **코드로 호출** |
| G | **llm_control 패턴** | Lite3_LLM (Int32 액션 코드) | 자연어나 음성을 액션으로 바꾸는 LLM 실습 |

## 4. 교육·연구 응용 아이디어

### 수준 0 — 앱만 사용 (코딩 없음, 입문·체험)
1. **보행과 지형 탐구**: Flat과 RUG(General, Grip, H-Step)를 같은 장애물 코스에서 비교한다. 성공률과 소요 시간을 기록하고 "왜 지형마다 보행이 다른가"를 토론한다.
2. **센서 원리 체험**: Auto Stop(초음파), Tracking(비전), Obstacle Avoidance(깊이)를 차례로 켜 보고 각각 어떤 센서를 쓰는지 추론한다.
3. **음성 명령 시퀀스 미션**: 음성 명령 15종만으로 코스를 통과하는 "말로 하는 프로그래밍"(알고리즘 사고).
4. **Pose 모드로 보는 자세각**: roll, pitch, yaw를 직접 조작해 보며 좌표계와 오일러각 개념을 익힌다.

### 수준 1 — 리모컨을 입력 장치로 (gamepad 라이브러리, 확장 지점 A)
5. **버튼 → 내 프로그램**: 리모컨 버튼 이벤트를 PC에서 받아 Python 또는 C++로 처리한다. 처음에는 로봇이 아니라 화면이나 시뮬레이터를 움직인다.
6. **리모컨으로 MuJoCo 시뮬 조종**: 실물 없이 학생 여러 명이 동시에 실습하고, 같은 조작 방식으로 실물에 넘어간다.
7. **원격조종 데이터 수집**: 리모컨 입력과 로봇 상태를 묶어 기록하고 → 모방학습 데이터셋을 만든다(연구용).

### 수준 2 — 코드로 앱 기능을 대체·확장 (ROS2, 확장 지점 C·F)
8. **블록·Python 미션 API**: `/cmd_vel`과 `/simple_cmd`를 감싼 `robot.forward(1.0)` 같은 교육용 래퍼를 만든다(이 저장소의 `edu/` 폴더).
9. **교사 승인형 실행**: 학생 코드는 자동 모드에서만 동작하고 교사가 앱으로 언제든 회수한다. 소프트웨어에서도 속도 상한과 지오펜스를 건다.
10. **웹 대시보드**: rosbridge와 브라우저로 텔레메트리(IMU, 관절, 배터리)를 시각화한다. 앱이 보여 주지 않는 데이터를 수업 자료로 쓴다.

### 수준 3 — 비전·AI (확장 지점 D·G)
11. **영상 스트림 + YOLO** 물체 찾아가기, AprilTag 따라가기.
12. **LLM 에이전트**: 자연어를 허용 목록(whitelist)에 있는 액션으로 바꾼다. Lite3_LLM을 ROS2로 옮기고 Claude API를 쓴다. 안전 계층 설계 자체를 학습 주제로 삼는다.
13. **앱 Tracking과 내 추종기 비교**: 같은 상황에서 공식 기능과 학생 구현의 성능을 비교 평가한다.

## 5. 제약과 주의
- 앱은 **비공개 소스**이고 앱-로봇 프로토콜은 공식 문서가 없다. 리버스 엔지니어링보다 **DEEP Robotics 기술지원에 인지 개발 매뉴얼과 통신 프로토콜 문서를 요청**하는 것이 우선이다(Pro 구매자에게 "통신 프로토콜 제공"이 명시되어 있음).
- 앱, 리모컨, 학생 코드가 **동시에 명령을 보내면 충돌**한다. 제어권 규칙(누가 언제 명령하는가)을 수업 운영 규칙으로 정해 둔다.
- 강한 Wi-Fi 간섭 환경에서는 사용 금지(매뉴얼). 교실의 공유기나 학생 핫스팟을 정리해야 한다.
- 물리 E-STOP 리모컨은 **항상 교사(또는 안전 담당) 손에** 있어야 한다.

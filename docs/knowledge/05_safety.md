# 05. 안전 수칙 (교육 현장용 요약)

출처: Lite3 Pro 사용자 매뉴얼, Lite3_MotionSDK README, sdk_deploy README

## 운용 전
- [ ] 배터리 75% 이상인가? 리모컨과 E-STOP 리모컨이 충전되어 있는가?
- [ ] E-STOP 버튼이 해제되어 있고 전원이 켜져 있는가?
- [ ] 외관 손상, 발바닥 마모가 없는가?
- [ ] 작업 공간: 반경 1 m 안에 사람·물·불이 없는가? 바닥이 미끄럽다면 Grip 보행을 쓴다.
- [ ] 교실의 다른 Wi-Fi 간섭원(핫스팟 등)을 껐는가?
- [ ] 계단·경사에서는 **아래쪽에 사람이 서지 않는다.**
- [ ] Long Jump는 전방 2 m를 비운 뒤 실행한다.

## 비상 대응 순서
1. 앱의 **⑦ STOP**: 소프트 정지, 로봇이 앉는다.
2. **E-STOP 리모컨** 버튼: 앉은 뒤 전원을 차단한다.
3. 위 두 가지가 안 되거나 연기·침수가 생기면 **전원을 끄고 배터리를 분리**한다. 물로 끄지 않는다(분말, CO₂, 폼 소화기 사용).

## SDK·저수준 개발 시 추가 규칙
- 관절 명령 첫 실행은 반드시 **호이스트(매달기)** 상태에서 하고 사람은 **5 m 밖**에 둔다(SDK README).
- 실행 전에 로봇을 Ready 자세로 놓는다(영점 복귀를 부드럽게 하려고).
- 통신 확인(상태 수신)을 먼저 하고, 그다음에 명령 전송 코드를 켠다.
- 접근하기 전에 E-STOP을 누르거나 `sudo ./stop.sh`를 실행한다.
- kp, kd, 토크는 **작은 값부터** 올린다. 명령이 1초 끊기면 자동 댐핑된다.
- SDK 사용으로 생긴 손상은 보증 대상이 아니다.

## 열·배터리
- 과열 보호가 걸리면 그 자리에 앉는다 → 10분 정도 식힌 뒤 Stand.
- 배터리 < 35%면 교체 준비, < 20%면 모션 명령을 거부한다.
- 배터리는 3개월마다 충방전한다. 장기 보관할 때는 분리하고, 0–40 ℃의 건조한 곳에 둔다.
- 운반할 때는 배터리를 분리하고, 케이스 로고 면이 위로 가게 한다.

## 수업 운영 규칙 (제안)
| 역할 | 책임 |
|---|---|
| 안전 담당(교사) | E-STOP 리모컨 소지, 앱 Auto/Manual 제어권 관리 |
| 조종자(학생) | 한 번에 한 명만 명령을 보낸다 |
| 관찰자 | 주변 통제, 이상 징후(다리 떨림, 과열 LED) 보고 |

# 01. Lite3 Pro 하드웨어

> 1차 출처: *Jueying Lite3 Pro User Manual V2.0.0-0 (2026-02-27)*. 그 밖의 출처는 표에 따로 적었다.
> ⚠️ = 출처끼리 값이 다르거나 실물에서 확인해야 하는 항목.

## 1. 제품 개요
- 정식 명칭: **Jueying(绝影) Lite3**, 제조사 Hangzhou Yunshenchu Technology(DEEP Robotics, 杭州云深处)
- 자유도 12개(다리 4개 × HipX / HipY / Knee)
- 에디션: Basic → (Basic AI) → Venture → **Pro** → LiDAR
- Pro 에디션의 특징: 모션 제어 SDK, 인지(perception) 예제 소스, 통신 프로토콜을 제공해 2차 개발(재개발)이 가능함

- 방진·방수 등급: 공식 표기 없음. 비·습기 환경에서는 사용 금지(매뉴얼).
- 관절 토크: 공식 절대값 없음(전작보다 "50% 증가"라고만 표기). URDF의 effort limit으로 확인할 것.

## 4. 외부 인터페이스 (Pro)
`Ethernet` · `Power(충전)` · `HDMI` · `USB 3.0` · 전원 출력 `24 V / 12 V / 5 V`
→ 외부 센서(예: Livox Mid-360 LiDAR, RealSense)와 보조 컴퓨터를 붙일 수 있다.

## 5. 관절 순서 (SDK 기준)
```
0 FL_HipX  1 FL_HipY  2 FL_Knee
3 FR_HipX  4 FR_HipY  5 FR_Knee
6 HL_HipX  7 HL_HipY  8 HL_Knee
9 HR_HipX 10 HR_HipY 11 HR_Knee
```
(FL=앞왼쪽, FR=앞오른쪽, HL=뒤왼쪽, HR=뒤오른쪽)
- 토크 제어 법칙: `τ = kp·(q_des − q) + kd·(dq_des − dq) + τ_ff`
- 모터 드라이버는 20 kHz 전류 폐루프로 동작한다. SDK 명령이 **1초 넘게 끊기면 자동으로 댐핑 보호 모드**에 들어간다.
